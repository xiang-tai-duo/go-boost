signtool.exe
============
signtool.exe is the Microsoft Sign Tool used for code signing, a component of
the Windows SDK. It is NOT permitted to redistribute the executable itself
(see the Microsoft Windows SDK license terms).

How to obtain:
  1. Download and install the Windows SDK (sign-tools component):
     https://developer.microsoft.com/windows/downloads/windows-sdk/

  2. Or install Visual Studio with the "Desktop development with C++" workload,
     which includes the Windows SDK.

After installation, signtool.exe can typically be found under:
  C:\Program Files (x86)\Windows Kits\10\bin\<SDK_VERSION>\<arch>\signtool.exe

Do NOT commit signtool.exe into this repository; it is listed in .gitignore.
